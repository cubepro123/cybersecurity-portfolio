# Wireshark Network Analysis

## Overview
Documentation-only lab project for practicing packet analysis with sanitized observations.

## Objectives
- Identify DNS behavior, TCP handshakes, and HTTP/TLS traffic traits.
- Practice Wireshark filtering and finding documentation.
- Produce concise findings and recommendations.

## Features
- Analysis template and example findings.
- Safe filter examples.
- Sanitized observation patterns.

## Technologies
- Wireshark
- Markdown

## Setup
Use an isolated lab VM and sanitized sample traffic.

## Usage
1. Follow `capture-analysis-template.md`.
2. Compare with `findings-example.md`.
3. Use scripts guidance in `scripts/README.md`.

## Example Output
See `findings-example.md` for sample conclusions.

## Security Considerations
No real packet captures or personal data should be committed.

## Lessons Learned
Structured packet analysis improves repeatability and communication.

## Future Improvements
Add additional protocol-focused templates (DHCP, ARP, ICMP).
