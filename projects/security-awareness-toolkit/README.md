# Security Awareness Toolkit

## Overview
Training-focused awareness content for phishing prevention, password/MFA hygiene, and incident reporting.

## Objectives
- Improve day-to-day security decision making.
- Provide quick-reference checklists for common risks.
- Support educational awareness sessions.

## Features
- Phishing indicator checklist.
- Password and MFA checklist.
- Incident reporting checklist.
- Short awareness guide.

## Technologies

## Setup
No software setup required.

## Usage
Use these checklists during onboarding, classroom exercises, or security awareness practice sessions.
