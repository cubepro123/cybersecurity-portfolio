# Contributing

Thank you for improving this cybersecurity learning portfolio.

## Contribution Guidelines
1. Open an issue describing the educational or defensive value of your change.
2. Keep changes safe, legal, and authorization-focused.
3. Add or update tests for Python code changes when practical.
4. Use clear commit messages and update relevant documentation.
5. Do not include real credentials, private logs, personal data, or copyrighted evidence.

## Commit Message Tips
- Keep messages short, specific, and action-oriented.
- Prefer formats like:
  - `Add tests for login lockout behavior`
  - `Update learning tracker for week 3 progress`
  - `Document Wireshark DNS analysis evidence`

## What Counts as Useful Portfolio Evidence
- Sanitized command output or test results that show what you practiced.
- Screenshots from authorized local labs (no personal/sensitive data).
- Short reflection notes that explain what changed and what you learned.
- Links to updated documentation sections in this repository.

## Responsible Disclosure
If you find a security weakness in this repository's demo code:
1. Do **not** publicly post exploit details first.
2. Report it privately following [SECURITY.md](SECURITY.md).
3. Provide reproduction steps using sanitized data only.
