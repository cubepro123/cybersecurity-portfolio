# Security Policy

## Scope
This repository contains educational cybersecurity projects and documentation. Tools and scripts are intended for authorized local labs only.

## Authorized Use Only
- Only test systems you own or where you have explicit written authorization.
- Do not use these materials for unauthorized scanning, intrusion, credential attacks, or disruption.

## Reporting a Security Issue
Please report vulnerabilities responsibly by opening a private security advisory or contacting the maintainer through a private channel.

Include:
- Affected file(s) and feature(s)
- Reproduction steps (sanitized)
- Security impact
- Suggested fix, if available

Do not include secrets, private logs, or personal data in reports.
