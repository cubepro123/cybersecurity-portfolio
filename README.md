## How to use this portfolio
1. Pick one topic or project and study its README + files.
2. Practice in an authorized local lab only.
3. Update [docs/learning-tracker.md](docs/learning-tracker.md) (Review/Practiced/Finished).
4. Add evidence (sanitized outputs, screenshots, notes, or test results).
5. Commit the update with a clear message.

## Daily update workflow
```bash
git pull
# study + practice one focused task
make check

git add README.md docs/learning-tracker.md projects/<project>/README.md
git commit -m "Track progress: practiced Linux auth log analysis"
git push
```
