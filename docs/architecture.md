# Portfolio Architecture

## Structure Overview
- `projects/python-network-scanner/`: safe port scanning for lab targets.
- `projects/linux-log-analyzer/`: auth log parsing and detection summaries.
- `projects/file-integrity-monitor/`: SHA-256 baseline and drift detection.
- `projects/secure-login-demo/`: educational secure authentication patterns.
- `projects/wireshark-network-analysis/`: network analysis documentation only.
- `projects/soc-home-lab/`: SOC simulation design and incident workflows.
- `projects/digital-forensics-case-study/`: fictional evidence workflow case study.
- `projects/security-awareness-toolkit/`: user-focused awareness checklists.
- `projects/linux-security-notes/`: defensive Linux hardening notes.

## Project Progression
1. Start with command-line Python fundamentals.
2. Apply analysis and detection logic from logs and file integrity.
3. Expand into secure web authentication practices.
4. Build investigation and SOC documentation discipline.
5. Reinforce human-layer security with awareness content.

## Design Principles
- Educational and ethical by default
- Minimal dependencies where practical
- Clear documentation and reproducible examples
- Test coverage for core Python logic
