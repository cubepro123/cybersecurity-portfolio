# Cybersecurity Learning Tracker

Use this checklist to track your day-to-day progress as an Applied Computer Technology cybersecurity student.

## How to use this tracker
1. Open this file in GitHub and click the pencil icon (Edit).
2. Tick checkboxes as you move from review to practice to finished.
3. Add one short evidence note or link for important progress.
4. Commit with a meaningful message (example: `Track progress: practiced SSH log analysis`).

## Proficiency scale
- **Not Started**: Haven't reviewed this topic yet.
- **Reviewing**: Reading/watching and taking notes.
- **Practiced**: Completed at least one lab or exercise.
- **Finished**: Completed planned tasks for now.
- **Comfortable/Can Explain**: Can teach/explain core ideas clearly.
